# Smart Farm Management System (SFMS) — Mobile

An AI-powered, offline-first farm-management app for Somali farmers, built with
**Flutter** on top of a **Supabase** backend (PostgreSQL + Auth + Storage + RLS).

This is the **mobile app** (the primary platform per the product spec). The
backend it talks to is already live.

## Requirements

- **Flutter SDK ≥ 3.27** (stable channel) with Dart ≥ 3.6 — https://docs.flutter.dev/get-started/install
- An Android emulator/device (or iOS on macOS)

## First-time setup

This repo contains the app **source** (`lib/`, `pubspec.yaml`). The native
platform folders (`android/`, `ios/`, …) are generated by Flutter. From the
project root:

```bash
# 1. Generate the native scaffolding around the existing lib/ (won't overwrite it)
flutter create --org com.beeroai --project-name sfms --platforms=android,ios .

# 2. Fetch packages
flutter pub get

# 3. Run static analysis (fix anything it flags)
flutter analyze

# 4. Launch on a connected device/emulator
flutter run
```

The Supabase URL + publishable key are baked into
[`lib/core/config/supabase_config.dart`](lib/core/config/supabase_config.dart)
so the app runs out of the box. To point at a different project or keep keys out
of source, override at build time:

```bash
flutter run \
  --dart-define=SUPABASE_URL=https://YOUR-REF.supabase.co \
  --dart-define=SUPABASE_ANON_KEY=sb_publishable_xxx
```

## Auth note

Email confirmation is **enabled** on the Supabase project, so a real signup
sends a confirmation email before login works. For frictionless local testing,
disable it in the Supabase dashboard (Authentication → Providers → Email →
"Confirm email"), or configure SMTP to send real mail.

## Project structure

```
lib/
  main.dart                     app entry — initialises Supabase
  app.dart                      MaterialApp.router + theme
  core/
    config/supabase_config.dart connection settings (dart-define overridable)
    supabase/                   Riverpod providers for the client & auth state
    theme/                      Agro-Modernist Material 3 theme (colors, type)
    router/app_router.dart      go_router with auth guard
  models/                       Profile, Farm
  features/
    auth/                       login / register / forgot-password + repository
    shell/                      bottom-nav HomeShell + placeholders
    dashboard/                  Dashboard screen (Stitch design)
    farms/                      Farms list + create (live, RLS)
    profile/                    Profile + sign out (live), repository
```
